Setting up a new place anywhere on Earth

Terrain, land cover, imagery and (in Norway) road widths arrive by themselves. Two optional runs make the place complete, and each takes one command with the place's box (south, west, north, east):

  1. Trees where they really stand:
    python tools/canopy_tiles.py --bbox S W N E --out <instance>/config/orbisterrarum/canopy-cache
  2. Real building heights:
    python tools/gba_heights.py --bbox S W N E --out <instance>/config/orbisterrarum/heights
  3. Optional, for shops and door signs: python -m overturemaps download --bbox=W,S,E,N -f geojson --type=place -o places.geojson then /orbis import-places places.geojson in game.
  4. Optional, for a whole country offline: import its OpenStreetMap extract with /orbis import <file.osm.pbf>; without one, regions stream from Overpass as you explore.

What still has no source

Lakes and rivers still use a fixed depth per water body (Seascape covers the seas). Roof shapes measured from lidar wait for Geonorge to come back. The dimension holds 332 blocks under sea level, so the deepest fjords stop at 300 m. Everything else that is generated rather than downloaded, such as villagers, interiors, tunnel loot, caves, ores and structures, is by design.
