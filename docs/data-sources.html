Orbis Data Sources

Orbis Terrarum 1.1.1 · sources as of 4 Oct 2026 (rev 24: street map drawn from OpenFreeMap)

Every external dataset the mod reads, what it becomes in the world, how it gets in, and whether it works today. The world is built in five stages; the arrows show which source feeds which stage and the order the stage tries them in. National services (a country's photos, NGU, NVE, NVDB) are used automatically inside their country's outline; Kartverket's surface model whenever it answers from the player's network (its switch forces it on, with a notice at world creation saying whether it answers). Data Sources → Downloads by country shows, re-imports and deletes each source's copies.

Setting up a new place anywhere on Earth

Terrain, land cover, imagery, weather, rock types and (in Norway) road widths arrive by themselves. Two optional runs make the place complete, and each takes one command with the place's box (south, west, north, east):

  1. Trees where they really stand:
    python tools/canopy_tiles.py --bbox S W N E --out <instance>/config/orbisterrarum/canopy-cache
  2. Real building heights:
    python tools/gba_heights.py --bbox S W N E --out <instance>/config/orbisterrarum/heights
  3. In North Rhine-Westphalia and Bavaria, measured heights from the states' 3D buildings (streams the big files, keeps a few MB):
    python tools/lod2_heights.py --bbox S W N E --out <instance>/config/orbisterrarum/building-db-cache/de-lod2
  4. Lake depths (outside Norway's surveyed lakes):
    python tools/lake_depths.py --bbox S W N E --out <instance>/config/orbisterrarum/lake-depths
  5. Optional, for shops and door signs: python -m overturemaps download --bbox=W,S,E,N -f geojson --type=place -o places.geojson then /orbis import-places places.geojson in game.
  6. Optional, for a whole country offline: import its OpenStreetMap extract with /orbis import <file.osm.pbf>; without one, regions stream from Overpass as you explore.

What still has no source

River depths are estimated from their width: no dataset measures them at this detail. Measured roof shapes and building heights need Kartverket's surface model, which only answers from some networks (a VPN to Norway works); elsewhere heights come from tags and the building atlas. The dimension holds 332 blocks under sea level, so the deepest fjords stop at 300 m. Everything else that is generated rather than downloaded, such as villagers, interiors, tunnel loot, caves, ores and structures, is by design.
